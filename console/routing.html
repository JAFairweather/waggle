How this community treats what arrives

A public note that clears signature verification and the configured gates is classified into one routing lane below. The lane is decided by trust, not by content. Verification failures, consent holds, mutes, and an unconfigured quarantine are separate refusal outcomes — they do not “land” in a displayed destination. Read top to bottom: the higher the lane, the less it is questioned. This page verifies the bridge's own signed state in your browser and has no bridge-host access.

Why the counts and the names differ per lane. The bridge publishes a deliberately public-safe summary: no channel identifiers, no host paths, no relay targets, no message content. So some lanes can be listed by name and others only counted, and this page says which is which rather than implying it knows more than it does. A lane showing — instead of a number is not empty; it is unrecorded.
